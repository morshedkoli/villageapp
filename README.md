# 📱 Village App — Community Mobile Portal & Citizen Directory

[![Platform](https://img.shields.io/badge/Platform-Flutter_|_Android-02569B?style=for-the-badge&logo=flutter)](https://flutter.dev/)
[![Dart](https://img.shields.io/badge/Language-Dart-0175C2?style=for-the-badge&logo=dart)](https://dart.dev/)
[![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)](LICENSE)

A mobile community application engineered to connect rural and urban community members, local village institutions, emergency contacts, local businesses, and social development initiatives.

---

## 🌟 Core Capabilities

- **👥 Village Directory**: Comprehensive directory of residents, professionals, doctors, and emergency hotlines.
- **📢 Community Announcements**: Real-time broadcast alerts for local village notices, union council updates, and events.
- **🚑 Emergency Contacts**: Instant one-tap dialing for ambulances, blood donors, fire stations, and police.
- **🏛️ Institutional Directory**: Profiles for local schools, madrasas, mosques, and health clinics.

---

## 🚀 Quickstart

```bash
git clone https://github.com/morshedkoli/villageapp.git
cd villageapp
flutter pub get
flutter run
```
